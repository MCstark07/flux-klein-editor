\# Flux.2 Klein 4B Inpaint Studio



A standalone desktop app for editing images with Flux.2 Klein 4B. Everything comes pre-configured—no Python or ComfyUI setup required.



\## How to Use

1\. Download the app from the \*\*Releases\*\* section.

2\. Extract the folder anywhere on your PC.

3\. Double-click `run.bat` to open the editor.
